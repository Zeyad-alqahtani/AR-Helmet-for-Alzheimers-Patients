# My contributions and team context

This was a collaborative Computer Engineering graduation project at King Khalid University. The complete system combines hardware, vision, scheduling, location processing, persistence, and a caregiver interface.

The contribution statements below are supplied by the repository owner. The report establishes the team project but does not independently map every implementation task to an individual.

## CareGuard development and requirements

I developed the CareGuard web application by defining its requirements, features, and expected behavior, directing AI-assisted implementation through prompts, and iteratively refining the generated application. This work combined requirements definition with an iterative development process focused on the caregiver interface and its role in the broader system.

## Software integration

I worked with software modules provided by teammates, including the face recognition code. Using AI-assisted development workflows, I adapted and integrated these modules so they could work with the broader system and CareGuard application. This contribution involved integrating existing team software as well as developing the web application; it does not imply original authorship of every module.

## Practical hardware assembly

I participated directly in assembling the physical helmet prototype, connecting hardware components and peripherals, wiring the necessary connections, and setting up portable power connections using a power bank. This was practical hardware assembly and integration. My role did not include designing complex electronic circuits or custom PCBs.

## Raspberry Pi collaboration

After preparing and integrating the software, I shared the updated code with a teammate, who transferred and ran it on the Raspberry Pi connected to the development laptop. We collaborated to ensure that the software operated with the physical prototype and CareGuard application. Raspberry Pi deployment was a shared workflow, with the transfer and execution performed by my teammate.

## Testing, troubleshooting, and teamwork

I participated in testing the integrated prototype, addressing integration issues, and refining system functionality. Throughout development, I exchanged code with teammates, communicated requirements, and worked with them to resolve technical challenges.

These responsibilities developed software integration, hardware integration, and embedded-systems experience through hands-on work. CareGuard development exercised requirements definition and AI-assisted development; integrated testing exercised troubleshooting; code exchanges and joint problem-solving exercised teamwork and communication. The repository's evaluation results remain team-level results, with no invented individual performance metrics.

## Attribution boundaries

Face Recognition was manually programmed by another team member. Medication Detection may have been developed by that teammate with AI assistance, but its exact authorship remains unconfirmed. These distinctions prevent sole-authorship claims; they are not a ranking of team members' contributions.

The portfolio presents the system as a shared engineering achievement. My responsibility for adapting and integrating teammate-provided code is distinct from that code's original authorship. Ownership of team code, model development, testing, and deployment should not be attributed exclusively to me.
